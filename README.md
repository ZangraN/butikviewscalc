# Калькулятор просмотров Reels (Meta Business Suite)

Веб-приложение для автоматического извлечения и подсчета просмотров рилсов (Reels) и видео из экспорта / исходного кода **Meta Business Suite** (`business.facebook.com`), таблиц и текста.

## Основные элементы интерфейса:
1. **Поле для ввода содержимого** — поддержка вставки огромных фрагментов HTML (даже 3–10 МБ исходного кода страницы `XBizWebCometBizSuiteInsightsController`), скопированных таблиц, фрагментов DOM или текстовых списков. Есть кнопки быстрой вставки из буфера, очистки, загрузки файла и готовые демо-примеры.
2. **Кнопка «Посчитать просмотры»** — мгновенный анализ (горячая клавиша `Ctrl + Enter` / `Cmd + Enter`).
3. **Элемент с общим количеством просмотров** — суммарное количество просмотров по всем распознанным рилсам.
4. **Элемент с наибольшим количеством просмотров рилса** — максимальный результат среди рилсов и название самого популярного ролика.

---

## Дополнительные возможности:
- **Детализация по каждому ролику**: таблица с названиями, датами и количеством просмотров, отсортированная по убыванию с прогресс-баром популярности.
- **Поиск и фильтрация**: быстрый поиск по названию рилса в таблице.
- **Экспорт**: копирование итогового списка в буфер обмена и скачивание CSV-файла.
- **Умное распознавание**:
  - Полный HTML страницы Meta Business Suite с JSON Relay / ServerJS стримами (`reels_plays`, `video_play_count`, `metrics`, `inline_insights_node`).
  - DOM-разметка таблиц (`role="row"`, `role="gridcell"`, `tr`, `td`).
  - Числа с сокращениями (`тыс.`, `млн`, `K`, `M`, пробелы, запятые и точки).
  - Скопированные строки из буфера обмена (TSV/текст).
- **Светлая и тёмная темы оформления**.
- **Работает автономно**: без внешних библиотек и зависимостей.

## Как запустить:

### Вариант 1. Открыть напрямую в браузере (без сервера)
Просто откройте файл `index.html` в любом браузере (Chrome, Safari, Firefox, Edge).

### Вариант 2. Запуск локального сервера
```bash
npm start
# или
python3 -m http.server 3000
```
Затем откройте в браузере: [http://localhost:3000](http://localhost:3000)

### Запуск тестов
```bash
npm test
```
